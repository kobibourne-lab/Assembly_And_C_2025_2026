# Assembly & C Labs

This repository contains my Assembly and C practical work. The text-based Star Wars project is located in the `Project 01` folder.

## Star Wars Text Adventure

A text-based adventure game developed in Motorola 68000 Assembly. The player chooses between a Jedi or Sith character and progresses through 10 rooms, making decisions that affect their health and power.

The game includes different room events such as traps, pickups, enemy encounters and riddles. Some encounters require the player to have enough power, while incorrect riddle answers can reduce health.

The objective is to reach the final room and find the Kyber Crystal without losing all health.

## Gameplay

- Choose between Jedi and Sith
- Navigate through the rooms using left and right choices
- Manage health and power throughout the game
- Encounter traps, pickups, enemies and riddles
- Receive feedback through the on-screen HUD
- Reach room 10 and find the Kyber Crystal to win

The Jedi starts with higher health, while the Sith starts with higher power.

## Technologies

- Motorola 68000 Assembly
- EASy68K

## Concepts Used

- Subroutines
- Branching and conditional logic
- Loops
- Registers and memory variables
- Keyboard input
- String and number output
- Game-state management
- Input validation
